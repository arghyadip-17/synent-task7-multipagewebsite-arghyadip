## 📌 Overview

**Learnova** is a modern, responsive **multipage educational website** built using **HTML, CSS, and JavaScript**.
It demonstrates a clean UI design, structured navigation, and interactive frontend features.

---

## 🚀 Features

* ✅ Multipage structure (Home, About, Courses, Contact)
* ✅ Responsive design for mobile and desktop
* ✅ Interactive navigation menu (mobile toggle)
* ✅ Course filtering functionality
* ✅ Contact form validation
* ✅ Clean and modern UI/UX
* ✅ Reusable components (Navbar, Footer)

## 🧱 Tech Stack

* **HTML5** – Structure of the website
* **CSS3** – Styling and layout (Grid, Flexbox)
* **JavaScript (Vanilla JS)** – Interactivity and functionality
* **GitHub Pages** – Deployment

---

## 📂 Project Structure

```
├── index.html        # Home Page
├── about.html        # About Page
├── services.html     # Courses Page
├── contact.html      # Contact Page
├── style.css         # Main Stylesheet
├── main.js           # JavaScript Logic
```

## ⚙️ Functionality Breakdown

### 🔹 Navigation

* Mobile menu toggle using JavaScript
* Click outside to close menu

### 🔹 Courses Page

* Filter courses by category dynamically

### 🔹 Contact Page

* Form validation:

  * Required fields check
  * Email format validation
* Displays success message (frontend only)
